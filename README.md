# Drone Chase

Игра Roblox для двух игроков: охотник управляет боевыми дронами, беглец едет на спорткаре по мосту к финишу.

## Установка

1. `GameServer.lua` — вставить как **Script** в `ServerScriptService`.
2. `GameClient.lua` — вставить как **LocalScript** в `StarterPlayer > StarterPlayerScripts`.

Карта, машина, дроны и эффекты собираются скриптом из деталей Roblox, сторонние ассеты не нужны.
Для лучшей картинки в свойствах `Lighting` выберите `Technology = Future` (из скрипта это свойство не меняется).

## Управление

- Охотник: WASD — полёт, E/Q — вверх/вниз, ЛКМ — огонь, 1/2/3 — Скаут / Бомбер / Ракетчик.
- Беглец: W/S — газ/тормоз, A/D — руль.
